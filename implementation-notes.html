TUI Performance Implementation Notes

Design Decisions

  • Added a reusable versioned render cache in the TUI package instead of handwritten IPython-only cache fields.
  • Kept the cache key to width plus state version because wrapping, truncation, and padding are width-dependent.
  • Planned IPython state updates to bump the render state version unconditionally.
  • Implemented the cache as a single-entry helper named VersionedRenderCache. It is reusable, but this PR applies it only to IPython cells.

Deviations

  • Did not change existing traceback-only rendering behavior. The new cache tests use the existing output-plus-traceback shape so this PR stays focused on performance.

Tradeoffs

  • Global dirty-subtree caching remains out of scope because the current component contract does not guarantee reliable dirty propagation.
  • Structural equality is intentionally avoided because updateDisplay rebuilds state objects and comparing them would add work on the hot path.
  • Streaming cells still miss the cache on each chunk because update() advances the state version. The intended win is completed historical cells during later renders.
