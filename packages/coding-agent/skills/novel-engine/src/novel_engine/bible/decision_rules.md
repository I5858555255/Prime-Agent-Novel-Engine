# 创作口径判定规则库（Decision Rules）

本文件是 bible 的机读判定层：audit / concept_audit / 中纲校验据此自动判定
"章级意图是否合规"，无需逐章人工审阅。每条规则 = 历史判例的条款化沉淀。
判定优先级：规则表命中优先于概念解锁，两者都未命中 → 按 author_intent 卷级 forbidden。

## 揭示尺度分级（scale）

| 级别 | 含义 | 命中处理 |
|------|------|----------|
| forbidden | 完全禁止出现（无论铺垫还是点明） | hard block，进修复指令 |
| hint | 允许氛围/物证/传闻铺垫，但不得点明机制、根源、真相 | 放行；超密度上限则收紧 |
| allowed | 既定事实可提及/可描写 | 放行 |

### 规则适用卷范围（rule_applies）

### 判定化覆盖（covers_clauses）

每条规则声明覆盖的 author_intent 卷级 forbidden 条款（格式 vid#序号）：
- V01 四条：V01#1（正式修炼体系/师承）← R04；V01#2（修炼样式动作/呼吸法边界）← R01-R06；V01#3（陈老根来历）← R09/R10；V01#4（迷雾根源）← R07/R08/R11。
- V02 三条：V02#1（乾武帝动机）← R13；V02#2（残页用途）← R14；V02#3（筑基突破）← R15。
- 覆盖审计：audit 对当前卷统计 "forbidden N 条 / 已判定化 M 条 / 未覆盖 K 条"，K>0 时批次挂起待 bible 完善，不静默放行。

## 执行顺序（audit 判定伪码）

1. 规则表逐条匹配（R01-R11 按触发特征）；命中 → 按 scale 处置。
2. 未命中规则表 → 走 concept_unlocks 概念判定。
3. 仍未命中 → 对照 author_intent 当前卷 forbidden 条款。
4. 前两者都未覆盖且涉及伏笔 → 查 ending_bible 对应 F 编号的铺垫/回收窗口。
5. 全部未覆盖 → 放行；命中"需要新设定判定"特征的（新角色/新势力/新伏笔）→ 标记需人工完善 bible。
