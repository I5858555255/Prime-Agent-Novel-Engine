# 世界观设定

## 时代背景
沉碳界与地球以阴阳裂隙相隔。昆仑迷雾禁区原是低浓度活化氧险地，因陆烬（地球孤儿李淳，神魂跨界重生）降生暴走成死亡禁区。大乾皇朝是人族最后守门人，皇权管凡人、仙门控修士，互相利用。主题由"我要成仙"转向"为什么众生必须依靠仙"。

## 地理格局
- **雾隐村** — 昆仑外围荒村，陆烬出生、陈老根收养地。
- **昆仑迷雾禁区** — 天然裂隙，唯陆烬可吸收暴走活化氧。
- **青河县/大乾皇京** — 官府、武馆、江湖门派交织。
- **太虚仙门** — 正统宗门，设体修/丹修/阵修/剑修四脉。
- **云隐坊市** — 凡间通往修仙界的过渡交易场。
- **墟界** — 仙门之上更高维度战场，藏人皇遗迹。
- **仙庭旧墟** — 远古文明遗迹，人皇体系真相揭示地。

## 势力分布
- 铁风武馆/龙渊阁/血刀门 — 江湖门派，龙渊阁与血刀门世仇。
- 大乾皇朝/玄甲卫 — 皇室秘藏三件残物，暗卫首领裴九霄。
- 太虚仙门 — "候选人验证"实为监控收编凡人机制。
- 摄魂阁 — 暗中猎魂图谋"人造飞升"，受仙庭旧部意识操控。
- 血冥教 — 修"逆炼心魔"，人道分支异化，后期投诚。
- 仙庭旧部/仙庭意志 — 太初"绝对秩序"守护型意志。
