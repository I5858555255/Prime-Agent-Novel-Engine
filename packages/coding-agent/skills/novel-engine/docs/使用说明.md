## 1. 快速上手（本项目续跑/单章生成）

### 1.1 环境

- Python 3.12（本机 `D:\Program Files\Python312\python.exe`；代码无路径硬编码，
  任何解释器均可）；
- 依赖安装（`pyproject.toml`，含 httpx / jieba / json-repair / psutil）：

```bash
cd packages/coding-agent/skills/novel-engine
pip install -e src            # 或 poetry install
```

- API key **只**写 `src/novel_engine/.env`（AGNES profile 用 `AGNES_TOKEN_API_KEY`；
  引擎按 `config/llm_providers.json` 的 `api_key_env` 读 `AGNES_API_KEY` / `LLM_API_KEY`），
  永远不进 argv / json / git。
- LLM 供应商/模型/阶段路由：`config/llm_providers.json` + `config/switch_llm.py`
  （详见 [`config/LLM选择器使用说明.md`](../src/novel_engine/config/LLM选择器使用说明.md)）。

### 1.2 命令（一律在 `src/` 目录执行）

```powershell
cd packages\coding-agent\skills\novel-engine\src

# 生成一批章（断点续跑）
python -X utf8 -m novel_engine.scripts.run_volume --chapters 3800 --resume

# 无人值守长跑：无代理启动器 + 看护（含单实例锁/心跳）
python -X utf8 -m novel_engine.scripts.noproxy_launcher --chapters 3800 --resume
pythonw -X utf8 -m novel_engine.scripts.relay_watchdog --final-cap 3800 --initial-target 0

# 状态/统计
python -X utf8 -m novel_engine.scripts.status_snapshot
python -X utf8 -m novel_engine.scripts.batch_stats --log <run_volume日志>

# 中纲（30 章/片）：生成 → 修复 → 审计
python -X utf8 -m novel_engine.scripts.generate_mid_outline --vid V10 --start 3801 --end 3830
python -X utf8 -m novel_engine.scripts.outline_repair config/planning/mid_outline_V10_ch3801-3830.json
python -X utf8 -m novel_engine.scripts.audit_mid_outline config/planning/mid_outline_V10_ch3801-3830.json

# 质量探针 / 复核清单
python -X utf8 -m novel_engine.scripts.writer_degradation_probe --dir chapters/draft --limit 50
python -X utf8 -m novel_engine.scripts.review_worklist           # 产出 audit/review_worklist.*
python -X utf8 -m novel_engine.scripts.review_worklist --mark-reviewed 370,2683,3092

# 全书拼接目录
python -X utf8 -m novel_engine.scripts.assemble_full --total 3800
```

**纪律（3800 章实战沉淀）**：
- 永远单批次（共享 `runtime/checkpoint.json` / `state.db`）；
- 停止顺序：先杀看护（`relay_watchdog`），再杀生成（`run_volume`）——看护 120s 内自动重启；
- 进度口径：看**最大章 + 连续前沿**（`status_snapshot` 的"连续进度"行），
  不要信 `last_complete`（它是最近平移章，不是最大章）；
- DSH/Clash 环境剥 8 个 proxy 变量（`noproxy_launcher` 已自动处理；
  手动起进程时按 `watchdog-runbook` 的 `clean_env` 模式）；
- `git add` 只加自己改的文件；`--resume` 语义安全，误杀后直接放行。

## 2. 跨项目复用（新书任务最小起步集）

**直接搬（引擎 + 8 个流程脚本）**：StateDB / 质量门 / checkpoint / Session Tree /
`run_volume` / `relay_watchdog`（锁+心跳）/ `noproxy_launcher` / `batch_stats` /
`status_snapshot` / `assemble_full` / `outline_repair` / `review_worklist` /
`writer_degradation_probe`。改 `--final-cap` / `--dir` 参数即可，代码零项目绑定。

**改 1 个 yaml（创作约束）**：`config/constraints/project_constraints.yaml`
（A 路线类硬边界正则 / 伏笔锚点短语 / 合规尾注 / 角色替换表 / reviewer 硬约束）。
`audit_mid_outline` 与 `outline_repair` 均 pack-first 读本文件，缺省退回内置默认值。

**单一权威源（换书核心）**：`config/planning/volumes.json`
（卷 id/title/chapter_range + 顶层 `outline_file` + 每卷可选 `outline_marker`/`intent_marker`）。
`chapter_director` 的大纲解析、卷标题、阶段标题全读这里——换书改它，代码零改动。

**视角/文风**：`bible/style_bible.md` 第一行写视角（writer 自动注入场景系统提示）。

**重建 5 个规划文件（按新书）**：
`config/planning/volumes.json`、`config/planning/decision_rules.json`（R 条款化判例）、
`config/foreshadow/registry.json`、`config/planning/character_registry.json`、
`bible/*.md` 五件套。

**新建**：干净的 `runtime/`（checkpoint/state.db/日志）、`chapters/`、
新书的 `.env` key 与 `llm_providers.json` profile。

**照搬 6 条纪律**（§1.2 末尾）：中纲领先 ≥1 片、剥 proxy、单批次、停启顺序、
进度口径、git 纪律。

## 4. 已知边界（复用前必读）

- 锁的 create-read 窗口非原子：毫秒级双起仍靠"先验证再起"纪律（runbook 有排障行）；
- 多机部署需再加网络锁（超出单机范围）；
- `audit_mid_outline auto` 只审排序第一文件，全量巡检按目录逐个跑（`--all` 待加）；
- 伏笔 `resolve@` 逾期仍走 hard-gate → force-best（`review_worklist` P1 清单是消费入口）；
- 旧版 `使用方法指南.md` 的 SiliconFlow/Qwen 测试数据与 `start.sh` 入口为历史存档，
  现役入口以本文件 §1.2 为准。
