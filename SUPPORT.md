# Support

Use the repository's GitHub issues for reproducible bugs and focused feature requests. Include the Prime Agent version, operating system, terminal, provider, relevant configuration with secrets removed, reproduction steps, expected behavior, and actual behavior.

Before opening an issue:

1. Update to the latest stable release.
2. Run `prime-agent doctor` and include relevant non-sensitive output.
3. Check the documentation and existing issues.
4. Reduce the problem to the smallest safe reproduction.

Do not post `~/.prime/agent/auth.json`, API keys, OAuth tokens, complete private sessions, proprietary source code, or unredacted daemon and kernel logs. For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

Community support is best effort. Prime Intellect does not guarantee response times through public GitHub issues.
